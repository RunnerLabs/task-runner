# TaskRunner v0.9.7 Windows Beta

TaskRunner v0.9.7 adds more accurate and inspectable local AI planning, shared Pocket rooms, personalized pixel companions, wallpaper and acrylic display controls, and clearer task controls.

Calendar items now expose both **Clear schedule** and **Done**. The planner preserves omitted minutes and priorities, keeps explicit durations such as 15 minutes, and can export the user prompt, model conversation, extracted JSON, and live card values for evaluation.

The Windows installers include the updated EULA. TaskRunner does not change the Windows Wi-Fi profile; only the user can choose that setting. Use nearby sharing on a home or private network whose people and devices you trust.

The beta packages are unsigned. Windows SmartScreen or antivirus software may show a publisher warning. Download only from this repository and verify the SHA-256 checksums.
