# TaskRunner v0.9.4 Beta

TaskRunner v0.9.4 sharpens the desktop room workflow and expands Signal Lab into a compact, cross-platform network console.

## Highlights

- Refreshed TaskRunner branding and application icons across Windows and Linux.
- Task boxes now turn orange when selected, making the active assignment easier to see.
- Room managers can choose an existing task, create a new task, or add a blank local draft box before details are available.
- Signal Lab is available on Windows and Linux with a saved show-or-hide preference.
- The dedicated Signal Lab console adds live, read-only network status, compact graphs, color palettes, and graph-style controls.
- Existing LAN timer synchronization and mobile handoff behavior remain intact.

## Packages

- Windows 10/11 x64 setup executable
- Windows 10/11 x64 MSI package
- Linux x64 AppImage
- Linux x64 Debian package
- SHA-256 checksum manifest

The beta packages are unsigned. Windows SmartScreen or a Linux desktop environment may ask you to confirm the package before running it. Download TaskRunner only from this repository's official Releases page.
