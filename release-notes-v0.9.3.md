# TaskRunner v0.9.3 Beta

TaskRunner v0.9.3 makes LAN room timers feel live across Windows and Linux while expanding the mobile handoff workflow.

## Highlights

- Start, pause, reset, and completion events now reach room peers immediately.
- Listener displays check for room changes four times per second and stay aligned with the timer owner.
- Unchanged checks use lightweight revision responses instead of repeatedly transferring the encrypted room.
- Host-assigned revisions prevent Windows/Linux clock differences from rewinding or freezing timers.
- Mobile dashboards can run multiple task timers simultaneously.
- Mobile focus mode has a full-screen fallback for browsers that restrict the native fullscreen API.
