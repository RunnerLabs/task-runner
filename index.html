Native desktop

Choose your system.

TaskRunner runs locally on Windows and Linux. The application source stays private; only the approved release packages are public.

Windows 10 / 11 · x64

Windows installer

Use the standard setup program. The current public beta is unsigned, so Windows may show an unknown-publisher warning.

Download .exe Download .msi
Windows installation
Open the downloaded setup file and follow the installer. Allow TaskRunner through Windows Firewall when you want to host LAN rooms.
Linux · x86_64

AppImage or Debian

Use the AppImage on most distributions, or the native Debian package on Ubuntu, Debian, Mint, Pop!_OS, and related systems.

Download AppImage Download .deb
Linux installation
AppImage: chmod +x TaskRunner_0.9.4_amd64.AppImage ./TaskRunner_0.9.4_amd64.AppImage Debian / Ubuntu: sudo apt install ./TaskRunner_0.9.4_amd64.deb
Phone handoff

Scan once. Keep moving.

An administrator chooses a person and their tasks. TaskRunner turns that assignment into a short-lived QR link, while the phone keeps the received dashboard locally.

01Generate

Create a private QR for one person’s task packet from the desktop dashboard.

02Scan

Open the mobile dashboard in Chrome or Safari and start working immediately.

03Save or send

Keep an offline HTML recovery copy or share the complete dashboard by text or email.

Network help

Know what to check.

Open Signal Lab when a room cannot be found, a peer will not join, or syncing feels slow.

CAN'T FIND THE ROOM

Discovery

Confirm both computers are on the same router and the host is still running.

BEFORE JOINING

Connection Check

Confirm the host address and room details before opening the full room.

SYNC FEELS SLOW

Network Health

Check Discovery, Host, Peers, and Sync to see which part needs attention.

STILL NOT WORKING

Diagnostics

Run the checks and copy a safe report without including the room password.

Fast connection check: keep the host open → use the same local network → allow TaskRunner through the computer's firewall → run Connection Check.
