Phone handoff

Scan once. Keep moving.

An administrator chooses a person and their tasks. TaskRunner turns that assignment into a short-lived QR link, while the phone keeps the received dashboard locally.

01Generate

Create a private QR for one person’s task packet from the desktop dashboard.

02Scan

Open the mobile dashboard in Chrome or Safari and start working immediately.

03Save or send

Keep an offline HTML recovery copy or share the complete dashboard by text or email.

Network help

Know what to check.

Open Signal Lab when a room cannot be found, a peer will not join, or syncing feels slow.

CAN'T FIND THE ROOM

Discovery

Confirm both computers are on the same router and the host is still running.

BEFORE JOINING

Connection Check

Confirm the host address and room details before opening the full room.

SYNC FEELS SLOW

Network Health

Check Discovery, Host, Peers, and Sync to see which part needs attention.

STILL NOT WORKING

Diagnostics

Run the checks and copy a safe report without including the room password.

Fast connection check: keep the host open → use the same local network → allow TaskRunner through the computer's firewall → run Connection Check.
